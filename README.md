## 🧠 System Overview

**ATSLens** is a completed AI-powered ATS Resume Analyzer designed to evaluate resumes against job descriptions and produce structured resume intelligence, career-readiness insights and job-specific recommendations.

The system combines:

### `Document Processing + NLP + Skill Intelligence + TF-IDF + Cosine Similarity + ATS Analysis + Recommendation Generation`

---

## 🔬 ATSLens Intelligence Pipeline

```text
                       RESUME / JOB DESCRIPTION
                                  │
                                  ▼
                    ┌─────────────────────────┐
                    │    DOCUMENT PROCESSING  │
                    │      PDF / DOCX         │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │     NLP PREPROCESSING   │
                    │ Cleaning • Extraction   │
                    └────────────┬────────────┘
                                 │
                    ┌────────────┴────────────┐
                    │                         │
                    ▼                         ▼
          ┌───────────────────┐     ┌───────────────────┐
          │ SKILL EXTRACTION  │     │      TF-IDF       │
          │ & SKILL MATCHING  │     │  VECTORIZATION    │
          └─────────┬─────────┘     └─────────┬─────────┘
                    │                         │
                    └────────────┬────────────┘
                                 │
                                 ▼
                     ┌───────────────────────┐
                     │   COSINE SIMILARITY   │
```

name: Generate Contribution Snake

on:

  schedule:
    - cron: "17 3 * * *"

  workflow_dispatch:

permissions:
  contents: write

jobs:

  generate:

    runs-on: ubuntu-latest

    timeout-minutes: 10

    steps:

      - name: Checkout profile repository

        uses: actions/checkout@v4


      - name: Create generated assets directory

        run: mkdir -p assets/generated


      - name: Generate contribution snake

        uses: Platane/snk@v3

        with:

          github_user_name: ${{ github.repository_owner }}

          outputs: |

            assets/generated/github-contribution-grid-snake.svg?palette=github-light&color_snake=#38BDF8&color_dots=#F8FAFC,#E0F2FE,#BAE6FD,#A5B4FC,#8B5CF6

            assets/generated/github-contribution-grid-snake-dark.svg?palette=github-dark&color_snake=#38BDF8


      - name: Commit generated contribution animation

        run: |

          git config user.name "github-actions[bot]"

          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"

          git add assets/generated/

          if git diff --cached --quiet; then
            echo "No contribution animation update required."
            exit 0
          fi

          git commit -m "chore: refresh contribution animation"

          git push
