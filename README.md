## 🔍 ATSLens
### AI-Powered ATS Resume Intelligence Platform

<img src="https://img.shields.io/badge/Featured%20Project-ATSLens-38BDF8?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Status-In%20Development-F5F3FF?style=for-the-badge"/>

ATSLens is an **AI-powered resume intelligence platform** currently being developed to analyze resumes against job descriptions and provide structured ATS-focused insights.

**Key functionality**

- PDF and DOCX resume parsing
- Candidate information extraction
- NLP-based resume analysis
- TF-IDF vectorization
- Cosine similarity
- Resume vs Job Description matching
- ATS compatibility scoring
- Skill-gap identification
- Resume improvement recommendations
- Downloadable PDF reports

**Technology**

`Python` • `NLP` • `Scikit-learn` • `FastAPI` • `SQLite`
