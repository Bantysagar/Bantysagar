# 🏆 Featured Projects

## 🔍 ATSLens
### AI-Powered ATS Resume Intelligence Platform

<img src="https://img.shields.io/badge/PROJECT-COMPLETED-DCFCE7?style=for-the-badge"/>
<img src="https://img.shields.io/badge/AI%20%2B%20NLP-Resume%20Intelligence-E0F2FE?style=for-the-badge"/>

**ATSLens** is a completed AI-powered resume intelligence platform designed to evaluate resumes against job descriptions and generate structured ATS-oriented insights.

### Core Capabilities

- Resume parsing from **PDF and DOCX**
- Candidate information extraction
- NLP-based resume analysis
- TF-IDF text vectorization
- Cosine similarity analysis
- Resume–Job Description matching
- ATS compatibility scoring
- Skill-gap identification
- Resume optimization suggestions
- Structured PDF report generation

### Technology

`Python` • `NLP` • `TF-IDF` • `Cosine Similarity` • `Scikit-learn` • `FastAPI` • `SQLite`

### System Flow

```text
             Resume Upload
                  │
                  ▼
           PDF / DOCX Parser
                  │
                  ▼
          Text Preprocessing
                  │
                  ▼
             NLP Pipeline
                  │
          ┌───────┴────────┐
          │                │
   Skill Extraction    TF-IDF
          │                │
          │        Vector Representation
          │                │
          └───────┬────────┘
                  ▼
          Cosine Similarity
                  │
                  ▼
       Resume ↔ Job Matching
                  │
          ┌───────┼────────┐
          │       │        │
       ATS     Skill     Resume
       Score    Gap    Recommendations
          │       │        │
          └───────┼────────┘
                  ▼
              PDF Report
```
