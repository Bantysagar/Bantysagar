## 🧠 What is ATSLens?

**ATSLens** is a completed AI-powered ATS Resume Analyzer designed to evaluate resumes against job descriptions and produce structured resume, job-match and career-readiness intelligence.

It combines **document processing, NLP, skill analysis, TF-IDF, cosine similarity and backend application engineering**.

### Core Capabilities

✅ PDF / DOCX Resume Parsing  
✅ Resume Information Extraction  
✅ NLP Text Processing  
✅ Skill Extraction  
✅ Skill Matching  
✅ TF-IDF Vectorization  
✅ Cosine Similarity  
✅ Resume ↔ Job Description Matching  
✅ ATS Resume Scoring  
✅ Career Recommendations  
✅ MNC Readiness Analysis  
✅ PDF Report Generation

</td>
