## 🔍 ATSLens — AI-Powered ATS Resume Intelligence Platform

![Status](https://img.shields.io/badge/STATUS-IN%20DEVELOPMENT-FF4ECD?style=for-the-badge)
![Python](https://img.shields.io/badge/Python-0D1117?style=for-the-badge\&logo=python\&logoColor=00E5FF)
![FastAPI](https://img.shields.io/badge/FastAPI-0D1117?style=for-the-badge\&logo=fastapi\&logoColor=00FFB2)
![Scikit-learn](https://img.shields.io/badge/Scikit--learn-0D1117?style=for-the-badge\&logo=scikitlearn\&logoColor=F7931E)

**ATSLens** is an AI-powered resume intelligence platform being developed to evaluate resumes against job descriptions and provide structured ATS-oriented insights.

**Core functionality being developed:**

* PDF and DOCX resume parsing
* Candidate information extraction
* NLP-based resume analysis
* TF-IDF based text representation
* Cosine similarity based resume–JD comparison
* ATS compatibility scoring
* Skill-gap identification
* Job-specific resume recommendations
* Downloadable PDF reports

**Core Stack:** `Python` · `NLP` · `Scikit-learn` · `FastAPI` · `SQLite`
